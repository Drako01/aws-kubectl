# Changelog

Todos los cambios relevantes de esta guía se documentan aquí.

El versionado sigue Semantic Versioning cuando corresponde.

## [2.0.0] - 2026-09-10

### Added

- Helm como nuevo bloque principal de la guía;
- charts, repositories, values, install, upgrade, rollback, OCI y operación profesional con Helm;
- operación avanzada de Amazon EKS;
- Access Entries, Managed Node Groups, add-ons, upgrades y Pod Identity;
- troubleshooting con 15 casos reales de AWS, Kubernetes, EKS, Helm y Terraform;
- guía CI/CD con GitHub Actions, ECR, EKS, kubectl y Helm;
- autenticación AWS desde GitHub Actions mediante OIDC;
- estrategias de rollback, environments y separación CI/CD;
- comandos Helm y EKS avanzado incorporados al cheat sheet.

### Changed

- repositorio reposicionado conceptualmente como **DevOps Toolkit — Guía Profesional**;
- README reorganizado con cinco herramientas principales;
- logos de AWS, Kubernetes, Terraform, Helm y GitHub Actions reducidos y enlazados;
- índice ampliado y flujo DevOps completo documentado.

## [1.1.0] - 2026-09-10

### Added

- guía profesional de Terraform en español;
- fundamentos de Infrastructure as Code y workflow `init → plan → apply`;
- variables, outputs, locals, data sources y providers;
- state local y remoto, backends, locking, drift, import y workspaces;
- integración de Terraform con AWS;
- módulos, `for_each`, `count`, lifecycle y validaciones;
- seguridad de credenciales y datos sensibles;
- troubleshooting de Terraform y AWS Provider;
- flujo conceptual Terraform + AWS + EKS + kubectl;
- comandos Terraform incorporados al cheat sheet;
- logo, badge y enlaces oficiales de Terraform en el README.

## [1.0.0] - 2026-09-10

### Added

- guía profesional de AWS CLI v2 en español;
- instalación, configuración, perfiles, SSO, output y JMESPath;
- referencia práctica de servicios AWS de uso frecuente;
- automatización, seguridad y troubleshooting de AWS CLI;
- guía completa de fundamentos y operación con kubectl;
- workloads, networking, configuración, storage y RBAC;
- observabilidad, logs, debug, rollouts y mantenimiento de nodos;
- referencia organizada de comandos kubectl;
- capítulo específico de Amazon EKS con AWS CLI y kubectl;
- cheat sheet para consulta rápida;
- guía de contribución y enlaces oficiales.
